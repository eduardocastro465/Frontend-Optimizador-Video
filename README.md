# Optimizador de Videos

## Descripción
Esta es sitio web para una plataforma de edición y optimización de videos.
El objetivo es que funcione para laptops y dispositivos móviles.

## Tecnologias
- React
- Vite
- TailwindCSS
- TypeScript

## ¿Como ejecutar el proyecto?

1. Clona el repositorio
2. Ejecuta `npm install` para instalar las dependencias
3. Ejecuta `npm run dev` para iniciar el servidor de desarrollo
